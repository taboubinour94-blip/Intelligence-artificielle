# Intelligence-artificielle
IA
L'intelligence artificielle s'est essentiellement appliquée à analyser, classifier et prédire 
solver des problèmes educatif ou anticiper une tendance financière. 
Avec l'émergence de l'IA Générative, Nous vivons une véritable révolution dans le monde du numérique. 
L'IA ne se contente plus d'observer le monde ; elle le recrée et l'enrichit.
